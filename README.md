# Axo Buddy
1. Install Node.js, then in this folder: `npm install`
2. Put your Anthropic API key in config.json ("apiKey") or set ANTHROPIC_API_KEY
3. (Optional) drop a Minecraft-style font at assets/Minecraft.ttf (e.g. "Minecraft Regular" / Minecraftia)
4. `npm start`
Controls: drag = move | click = poke | double-click = ask Axo (Enter to send, Esc to cancel) | right-click = pause / glance now / quit
macOS: allow Screen Recording for Electron in System Settings > Privacy & Security.
